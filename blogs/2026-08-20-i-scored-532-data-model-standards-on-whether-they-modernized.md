There is a layer underneath every API I profile that I have never been able to point at as a whole. HTTP and OpenAPI describe how you move data. FHIR, ISO 20022, IEC CIM, NIEM, and a few hundred others describe what the data actually is — the entities, the attributes, the relationships, and the controlled values that fill them.
