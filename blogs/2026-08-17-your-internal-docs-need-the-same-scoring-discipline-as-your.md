Joyce Stack has published a set of Claude Code skills that do information-architecture analysis on a Markdown documentation corpus, and it is the most directly useful enterprise work I have seen come out of the skills format so far. The plugin is markdown-ia-skills. It is three skills meant to run in sequence against a git repo or a folder of .md and .mdx files.
