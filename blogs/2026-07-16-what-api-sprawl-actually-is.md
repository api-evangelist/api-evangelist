API sprawl is the uncontrolled, fragmented proliferation of APIs across an organization’s IT environment. That is the clean definition, but the reality is messier, and it is the mess I have spent sixteen years walking into. APIs are the sets of rules and protocols that let software applications talk to each other and exchange data, services, and functionality.
