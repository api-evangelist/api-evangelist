I have been around API gateways long enough to have watched them get sold as the answer to every problem in the space, over and over, for more than a decade. And I have come to a somewhat unpopular conclusion: the gateway is a tired concept, not because the technology is bad — it is often fine — but because the gateway has almost never really been about the technology. The gateway is about power.
