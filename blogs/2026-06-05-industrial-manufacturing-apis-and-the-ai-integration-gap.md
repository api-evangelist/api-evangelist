A catalog of 421 industrial manufacturing API providers revealed that only 5 out of 56 explicitly API-facing providers had publicly discoverable OpenAPI specifications, with Cognite, Limble CMMS, Inductive Automation Ignition, Factory I/O, and Formant among the exceptions. The analysis identifies three layers of the industrial API stack — data platforms, operations platforms, and maintenance/asset management — and notes that the operational technology floor (PLCs, SCADA, CNC controllers) largely does not speak REST natively. Inductive Automation adding an OpenAPI-compliant REST API to Ignition 8.3 is highlighted as a meaningful signal that SCADA is beginning to grow an HTTP surface.
