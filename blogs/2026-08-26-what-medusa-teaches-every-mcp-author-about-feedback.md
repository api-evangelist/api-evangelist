Every so often I read a post from a company that quietly reframes something I thought I already understood, and I have to go tell everyone about it. This time it is Medusa, the open-source headless commerce platform, and a short post by Oliver Juhl called Two Things Every MCP Author Should Add. The setup is simple: Medusa runs a remote Model Context Protocol server that exposes their documentation to coding agents, so when you are building on Medusa with an AI assistant, the agent can look up commerce modules, framework concepts, and APIs while it writes your code.
