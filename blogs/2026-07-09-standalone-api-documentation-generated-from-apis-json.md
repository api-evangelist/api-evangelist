This is the next stop in my daily walk through the API Commons tools, and it is one I have wanted for a long time: a way to hand somebody a single APIs.json and have it turn into real, readable documentation without standing up a service to make it happen. API Documentation does exactly that. You give it an APIs.json, and it renders the whole thing as HTML you can read, share, or ship.
