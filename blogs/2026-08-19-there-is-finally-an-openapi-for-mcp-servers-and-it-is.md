I have spent a lot of this year watching everyone ship Model Context Protocol servers and almost no one describe them. We went straight from “MCP is interesting” to “here is our MCP server” without stopping at the part where you write down, in a machine-readable way, what the thing actually exposes. That gap has been bugging me, because it is exactly the gap OpenAPI filled for HTTP APIs and AsyncAPI filled for event-driven ones.
