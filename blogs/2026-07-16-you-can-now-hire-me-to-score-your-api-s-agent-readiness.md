A few months back I published an Agent Readiness framework on GitHub–a plain, nine-dimension model for scoring whether an API surface can actually be driven by an autonomous agent, not just read by a human developer. I built it as an open thing anyone could use to score themselves or a third party, scored 0 to 3 across each dimension, with a reference set of what good looks like. I did not build it to sell anything.
