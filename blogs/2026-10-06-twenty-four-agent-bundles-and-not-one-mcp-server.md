APIMatic has been generating SDKs from OpenAPI for eleven years. Last month they put up a public marketplace of agent context bundles at context.apimatic.io — twenty-four APIs, MIT licensed, installable with npx context-plugins install square. I pulled their catalog.json and counted what is actually in the bundles.
