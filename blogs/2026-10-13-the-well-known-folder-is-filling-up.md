I was reading through Open Resource Discovery this morning — SAP’s protocol, now under the Linux Foundation Europe’s NeoNephos, for a system to describe the APIs and events it exposes — and noticed it starts the way so much does lately: at /.well-known/open-resource-discovery. Last week the Personal Agent Protocol told companies to publish /.well-known/poppy.json, and MCP Server Cards pointed domain discovery at /.well-known/ai-catalog.json. The Dataspace Protocol requires /.well-known/dspace-version.
