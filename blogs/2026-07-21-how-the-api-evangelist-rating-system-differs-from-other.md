There is a small industry forming around scoring whether an API is ready for AI agents, and I am glad it exists, because it means the question is finally being taken seriously. But most of the agent-readiness scores I see share the same two limits, and the API Evangelist Rating System was built to avoid both of them. The first limit is that they treat agent readiness as the whole question, when it is actually the last question.
