Vercel Labs has a new coding agent called fx. It is a small native binary, around 6MB, written in Zig, Apache-2.0 licensed, and on GitHub at version 0.0.13 with a banner telling you it is experimental and will change often. There is no shortage of coding agents right now, and I am not going to tell you this one writes better code than the others.
