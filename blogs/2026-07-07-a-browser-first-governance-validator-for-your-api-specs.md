I keep telling teams that governance should be something you can reach for in the moment, not a service you file a ticket against. So I am spending this stretch walking through the governance tools I have been building under API Commons, one per day, and I am starting with the simplest and most useful one to have open in a tab: API Validator. Paste a document, see what your rules say about it, and move on.
