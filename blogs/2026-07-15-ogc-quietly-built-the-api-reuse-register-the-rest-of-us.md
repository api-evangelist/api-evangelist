I spend a lot of my time arguing that the API economy has a reuse problem. Every team rebuilds the same bounding box parameter, the same pagination scheme, the same error object, the same link relation, slightly differently, forever. We talk about it constantly and we almost never ship the thing that would actually fix it: a shared, machine-readable, testable register of the pieces everybody keeps rebuilding.
